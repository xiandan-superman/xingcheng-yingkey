# 星橙·映钥：视觉与交互规范

本规范整理并扩展现有橙色品牌，三端共享语义，分别优化现有页面，不进行新品牌方向选择。

## 共用基础

- 主色：#B54708；悬停：#943905；柔和选中背景：#FFF2E8。
- 正文：#243041；次要文字：#596779；分隔线：#DCE2E8。
- 浅色工作区：#F4F6F8；面板：#FFFFFF；输入控件背景：#FFFFFF。
- 成功：#246747；错误：#A3342A；警告：#8A4C16。
- 中文产品字体使用 Microsoft YaHei UI / Microsoft YaHei，西文跟随 Segoe UI；不依赖网络字体。
- 字级：12/13/14/16/18/24/28；数据使用等宽数字，不将等宽字体用于普通中文。
- 间距：4/8/12/16/20/24/32；控件圆角8，面板12，播放器画面12。
- 图标采用同一套2px描边SVG；装饰图标隐藏于辅助技术，按钮保留可读名称。
- 状态需要文字与颜色共同表达；重要错误放在操作附近并保持可见。

## 播放器

观看区是主界面；宽屏以播放器加右侧课程/许可工具栏构成。窄窗口工具栏置于画面下方。
保留沉稳暗色观看区域及橙色主操作，控制整体高度，让播放、许可与状态提示在常见窗口中易于找到。
首次使用说明只包含真实的设备请求、许可导入、打开视频三个步骤；有许可后降低引导权重。
课程列表显示当前选择，选择不自动播放、不消耗次数。播放中禁止额外装饰动画。

## 管理端

浅色高密度工作区；保持侧边导航及工作流。加密、分组、授权采用相同的表单、工具栏、结果表和状态标签。
当前任务、输入文件与主按钮优先；高级规则渐进披露。导出、上传等操作仍按实际含义区分。

## 网页平台

浅色控制台，与管理端统一。登录页明确产品与账号输入；授权表格强调设备、次数和状态。
手机上导航与筛选换行，表格内部横向滚动；不让整页横向溢出。弹窗保留键盘退出和可见焦点。

## 动效命题

- 核心动效用于反馈：状态提示出现、任务完成/失败、列表选中、弹窗展开。
- 常规反馈120–180毫秒，弹窗最多220毫秒；退出快于进入。
- 使用本地GSAP对需要打断或重播的状态反馈控制；简单悬停与焦点使用CSS。
- 默认内容可见，不以动画完成作为允许操作或显示结果的条件。
- 减少动态效果模式去掉位移，保留即时状态与颜色反馈；页面隐藏时终止非必要动画。
- 不设置滚动视差、自动循环装饰、加载入场编排或播放器背景特效。

## 验收

播放器至少检查1080、800宽度；管理端1440、1280、1080；网页1440、1024、800、390。
覆盖空内容、长标题、长设备备注、失败、忙碌、只读权限、键盘焦点、减少动态效果和200%缩放。
