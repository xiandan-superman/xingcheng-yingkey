# 星橙·映钥：现有产品事实

本轮为现有产品的分阶段视觉与交互优化，依据已运行的 v0.8.1 和本次用户要求记录；不进行从零产品设计或改换品牌。

- 发片方在 Windows 管理端本机加密、分组、导入观看设备请求、签发及上传授权记录。
- 观看方使用 Windows 专用播放器，导出请求、导入许可、选择视频并手动验证播放。
- 网页控制台用于文件记录、网页本地加密、在线授权、操作记录与账号权限管理。
- 次数、到期、设备、水印及播放规则由已签名许可决定；线上停用存在复查及断网宽限。
- 用户为非专业技术人员，界面需要中文、直接反馈、可找回的错误与清晰的任务主次。
- 保留橙色品牌与现有标志；优化限制于前端呈现与必要的状态同步，不改变加密与授权协议。
- 本地测试使用隔离数据，不自动部署线上。

用户未指定新的艺术风格；本轮沿用现有品牌，以实际任务清晰、观看沉浸和信息可读性为验收依据。

2026-10-22：用户明确要求线上部署后，v0.9.0 已部署并通过公网验收；原密钥、账号和原有授权计次保留。后续测试继续优先使用隔离数据。
