# 后台删除与回收站

网页后台版本：v0.10.2。桌面端和观看方无需为本次后台更新重新安装。桌面成品请从GitHub发布页下载。

## 可删除的内容

| 内容 | 删除规则 |
|---|---|
| 已结束的加密任务 | 创建者或管理员可删除；移入回收站，不会被旧客户端再次同步回来 |
| 正在处理的任务 | 不允许直接删除；先结束任务。长时间失联任务需核对实际状态 |
| 后台文件记录 | 创建者或管理员可删除；存在未删除的关联授权时阻止删除 |
| 播放授权 | 仅管理员可删除；同时停用授权并撤销在线会话 |
| 空课程分组 | 可删除；有视频的分组需要先移出视频 |
| 操作日志 | 不提供用户手动删除按钮；按现有规则保留最近500条 |
| 员工账号 | 在量子星橙账号中心管理；停用员工不删除其历史业务记录 |

删除文件记录不会删除操作电脑上的原视频或加密视频。离线许可不能通过线上删除操作远程收回；在线授权正常联网约20秒复查，断网最多到90秒宽限结束。

## 回收站

在网页左侧进入“回收站”，可恢复本人有权限操作的记录；管理员可处理公司全部记录。

关联文件也被删除时，应先恢复文件，再恢复授权。恢复授权后仍为停用状态，需要管理员另行明确启用。播放次数、有效期和签名不会重置。

已删除的授权不能通过重新上传、重复登记或恢复启用接口绕过回收站。后台保留删除标记、历史计数和恢复所需记录，不提供“永久清空”按钮，避免误删或重置计数。

若空分组在清理中被删除，恢复的文件可能显示在未分组中，可重新归组。

## 验证

99项自动业务测试通过；实际 Chrome 验证删除确认、文件删除和恢复、任务删除、桌面与手机回收站，以及本机加密文件仍存在。

真实引擎验收验证：删除授权后正在播放的在线会话失效；重复上传和启用被阻止；恢复后保持停用且原计数不变；再次明确启用后正常累加次数。
